MC 适配约定
1. 玻璃面板的 backdrop-blur 在 MC 中通过 Blur.area (Kawase) 实现，作为可选项（默认关），关闭时面板不透明度提升到 94% 兜底，不影响可读性。
2. HTML 尺寸按 2x 换算到 GUI 单位：面板圆角 18px -> 9，控件 10px -> 5，胶囊 -> 高度/2。
3. 阴影仅为原型装饰，MC 不实现；描边用 roundedBorder + rgba(255,255,255,0.08)。
4. 动画统一用现有 Animator + BezierEasing(0.25, 0.1, 0.25, 1)，时长 150-200ms，仅做透明度/位移/缩放插值，无逐帧滤镜。
